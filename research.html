A Rashomon Diagnostic Framework for Model Disagreement in Psychological ML

A diagnostic framework for quantifying and interpreting disagreement among near-optimal ("Rashomon") models in psychological machine learning. Demonstrated on NHANES depression prediction with logistic regression, Random Forest, and XGBoost to expose hidden instability in model-based inference.

Quantization PyTorch Mixture-of-Experts Private
WeightForge — weight-only quantization library for dense and MoE LLMs

A research library that quantizes the linear weights of a PyTorch model, keeps activations and the KV cache in floating point, and refuses to make a claim it has not measured. 33 registered methods are compared under a single harness at honest effective bits-per-weight — scales, zero-points and codebooks are all charged, so 4-bit at group 128 is reported as 4.125 rather than 4. Quality rankings are backed by paired significance tests rather than point estimates, and results are evidence-graded so the harness refuses to mix machines or probes silently. MoE structure is understood natively: routed experts, shared experts and routers are distinguished and can take different precisions, and a route-aware allocator probes which experts routing actually reaches and discounts the rare ones. Calibrated methods (GPTQ and relatives) run block by block so only one transformer block's statistics are resident at a time, with decoder blocks located structurally rather than from a per-architecture manifest. Ships preflight coverage accounting that reports four disjoint parameter buckets, a bounded per-tensor damage sample, a regression-gated benchmark against a baseline recorded on the same device, and non-executable safetensors bundle export.

2.49× decode vs FP16 (7B, L40S) · +15.4% over bitsandbytes 0.50.0 · 3.10× less weight memory · +0.21 perplexity (+3.4%) · 33 methods · 2,277 tests

BankMind - production-grade RAG for financial intelligence

Two specialised pipelines (regulatory compliance + credit analysis) over a unified Qdrant infrastructure with 32,963 indexed chunks. Five Matryoshka dense embedding dimensions plus SPLADE++ and BM25 sparse vectors with native hybrid search. Rule-based guardrails: citation enforcement, numerical grounding, staleness warnings, confidence scoring, and temporal-query mismatch detection. 5-tab Gradio dashboard deployed on Hugging Face Spaces.

NA Tech Jobs - production ML platform for the North American senior DS/ML market

End-to-end ML platform answering job-search questions standard tools cannot: actual senior salary distributions by location, current hiring trends at specific seniority levels, and resume-to-opportunity alignment. Weekly asyncio ingestion from 6 ATS platforms (Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Workday tenants), Pandera schema validation, parquet snapshots versioned on Hugging Face Hub. Four trained models: XGBoost salary regressor with Optuna tuning; frozen sentence-transformers/all-MiniLM-L6-v2 + multinomial LR for seniority (7 classes) and role-family (6 classes) classifiers; regex-first skills extractor with optional NuExtract fallback. Closed-loop ops: weekly Evidently PSI drift detection, monthly champion/challenger retraining gated on +1 percent primary metric and -2 percent secondary, GitHub Actions CI for ingest/drift/retrain/deploy. Runs on a single $9/month Hugging Face Space.

Agentic RAG LangGraph-style Qdrant · LanceDB Terraform
RAG Architecture Advisor - agentic advisor for retrieval architecture

Maps a described situation to a defensible requirement vector, retrieves from a curated RAG-architecture corpus, and emits a pipeline recommendation together with a build plan, a structured design plan, a literature map, linked pipeline and deployment views, a Terraform module sketch, stated strengths and weaknesses, and the decision log that produced them. Runs as a Gradio Space over a LangGraph-style state machine with a startup-built retrieval index and bounded reflection; the detailed UI accepts follow-up answers for pending attributes and an explicit conflict-resolution value, then reruns the same graph with those values. The corpus is committed markdown catalogued by an authoritative manifest storing path, namespace, domain, trust tier, and tags, chunked at startup into an in-memory store — the default lexical retriever needs no persistent database, while LanceDB and Qdrant back deployment-grade dense retrieval. Deep-thinking mode adds a parallel research pass across four agent roles (literature review, agent-framework review, community implementation review, and Spaces review), fetching full text of selected public references and extracting approach, implementation notes, and limitations.

llama.cpp VS Code Air-gapped
Restricted Local Coder - private coding assistant for locked-down workstations

A self-contained VS Code assistant for a machine where Ollama, LM Studio, Docker, Python packages, Hugging Face, and administrator rights are all unavailable. The repository builds a platform-specific VSIX embedding a pinned llama.cpp server; on the target laptop the extension starts that binary on loopback, verifies an approved GGUF by mandatory magic-byte and SHA-256 checks, and provides streamed coding chat, explain/review/refactor/debug/test commands, and optional fill-in-the-middle for profiles that declare FIM support — refusing those requests rather than sending control tokens to a model that never saw them. Agent mode is off by default and, when enabled, is argv-prefix permissioned with no shell, workspace-confined paths, a secret deny-list, a bounded step count, and an audit log; file editing is a second switch again, and every edit is applied through the editor so Ctrl+Z undoes it. Loopback-only server, random SecretStorage bearer key, one inference slot, offline runtime mode, and the server's own agent/tool/MCP surfaces disabled so permission is decided in one auditable place. No third-party npm runtime dependencies.

0 malformed tool calls in 190 · 0 ambiguous edits · 32 GB CPU-first target

Inference Serving GGUF · safetensors Docker · Prometheus
Internal MoE Inference Service - offline-capable serving for private checkpoints

A secure HTTP/SSE inference service for locally mounted or private-S3 decoder-only checkpoints, shipping the containerized workload without any model weights or deployment infrastructure of its own. Artifacts are resolved and verified once against a versioned JSON manifest — SHA-256, byte size, safe-path, allowed-file and symlink validation — then one model is loaded, warmed, and reused for every request through a background lifecycle of resolve, validate, preflight, load, warmup, ready. Engines are format-locked: safetensors run on offline Transformers, GGUF on a pinned official llama-server supervised as a loopback-bound process with an ephemeral internal API key, no web UI and no agent mode. Serves OpenAI-shaped streaming and non-streaming completions behind bearer auth, request-size limits, request IDs, and redacted JSON logs, with bounded inference concurrency, queue timeout and backpressure, generation timeout, and cancellation signalling. Non-root, read-only-compatible image; CPU CI builds and serves a real tiny Qwen2-MoE checkpoint entirely offline.

zeroshotGPU - agentic zero-shot document parser

A self-hosted parsing control plane that treats document extraction as a multi-step decision process: profile pages (scanned vs. digital, table density, multi-column layout, formula density), route to specialised parsers (Docling, PyMuPDF, Marker, MinerU, olmOCR, PaddleOCR, Unstructured), merge candidates with conflict detection, verify against eight metric families (layout F1, table-structure score, formula CER, retrieval recall@k + MRR, parser disagreement, repair resolution/regression, parser contributions, throughput), then iteratively repair weak regions deterministic-first (table normalisation, header/footer marking, caption attachment) before invoking Qwen2.5-VL-3B on ZeroGPU. Emits retrieval-ready chunks across a strategy ladder (fixed-token to recursive-structure to parent/child to page-level to table to figure to semantic) with SHA-256 checksummed artifacts. Three dataset loaders, dual API (Python CLI + Gradio), 254 unit tests passing.

PWA IndexedDB Zero-dependency
Acoustify - local-first segmented player for long-form audio

A dependency-free, installable music library for long-form sources, designed to deploy as-is to GitHub Pages with no application server, cloud database, API key, build framework, or account system. Long-source segmentation makes every saved timestamp range behave like its own track: selecting a row seeks to the track start while adjacent tracks from the same source continue without reloading the underlying media. The browser remembers likes, listening history and play counts, playlists, volume, shuffle/repeat/autoplay state, the current queue, and the last playback position, with JSON backup and import. Local masters you own are stored as Blobs in IndexedDB and played without transcoding. Android media-session controls, an offline app shell, an editable persistent queue, a Catalog Studio for adding sources, and a timestamp calibrator with current-time capture and half-second nudging.
