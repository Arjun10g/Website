WF Private
Quantization PyTorch MoE-aware

WeightForge

A weight-only quantization library for dense and mixture-of-experts LLMs. 33 registered methods compared under one harness at honest effective bits-per-weight — scales, zero-points and codebooks all charged — with quality rankings backed by paired significance tests rather than point estimates. Measured 2.49× decode over FP16 at 7B and +15.4% over bitsandbytes 0.50.0 on an L40S, at 3.10× less weight memory for +0.21 perplexity. 2,277 tests.

RC Self-hosted
llama.cpp VS Code Air-gapped

Restricted Local Coder

A private coding assistant for locked-down workstations where Ollama, Docker, Python packages and Hugging Face are all unavailable. Ships a platform-specific VSIX embedding a pinned llama.cpp server, verifies an approved GGUF by SHA-256, and serves streamed chat, selection commands, and optional fill-in-the-middle on loopback only. Agent mode is argv-prefix permissioned with no shell — 0 malformed tool calls and 0 ambiguous edits across 190 validated calls. No source ever reaches a cloud API.

MI Self-hosted
Inference GGUF · safetensors Docker

MoE Inference Service

Offline-capable HTTP/SSE inference service for locally mounted or private-S3 checkpoints. Resolves and verifies artifacts once against a versioned manifest (SHA-256, byte size, safe-path, symlink checks), loads one model, warms it, and reuses that resident instance for every request. Format-locked engines: safetensors via offline Transformers, GGUF via a pinned loopback-bound llama-server with no web UI. Bounded concurrency with queue backpressure, Prometheus metrics, non-root read-only container.
